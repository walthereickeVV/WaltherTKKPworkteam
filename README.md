# 🏗️ PROFSTROY — Интерактивный рекрутинговый лендинг для строителей

> **Версия 2.0** | Год выпуска: 2026 | Стиль: неоновый индастриал + стекломорфизм

Современный, высококонверсионный одностраничный сайт для привлечения рабочих на строительные объекты. Разработан с акцентом на визуальный вайб реальной стройки, интерактивность и простоту использования.

|---|------|----------|
| 1 | **Фон — недостроенный монолитный дом** | Реалистичное фото стройки с затемнением, создающее атмосферу |
